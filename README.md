# R.E.P.O. Takeover

**Garry's Mod** × R.E.P.O. · visual · idea by the team

Bring R.E.P.O. into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put R.E.P.O. into Garry's Mod: yellow robots haul loot while tiny gnomes squeak and the bank bar fills.

## Install

Unzip the mod folder into a new folder inside garrysmod/addons, start Sandbox on any map and play. Robots, loot, the green extraction point and the Gnome and Huntsman monsters appear on their own.
